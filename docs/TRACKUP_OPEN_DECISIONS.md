# TRACKUP OPEN DECISIONS & ASSUMPTIONS LOG

Before starting Phase 1 implementation, review the following open decisions. Each includes a recommended default so implementation will not be blocked if you prefer to adopt the recommendation.

| ID | Decision Topic | Context & Impact | Recommended Default | Status |
| :--- | :--- | :--- | :--- | :--- |
| **OD-1** | **Manhwa vs. Manhua (Chinese Comics) Classification** | AniList's `MediaType.MANGA` returns comics from Japan (`JP`), South Korea (`KR` - Manhwa), and China (`CN` - Manhua). Should Chinese `CN` titles fetched from AniList be grouped under `manhwa` or `manga`, or should we add a 7th enum value `manhua`? | Map `KR` to `manhwa`, `JP` to `manga`, and allow `CN` to map to `manhwa` (or add `manhua` to the `media_type` enum before running Migration 001). | **Needs Confirmation** |
| **OD-2** | **Long-Running Anime Episode Numbering (Seasonal vs. Absolute)** | TMDB organizes long-running anime (e.g., *One Piece*) into seasons, whereas AniList and MAL track absolute episode numbers (`Episode 1 to 1100+`). | Store TMDB `season_number` + `episode_number` for structured season accordions AND populate `catalog_episodes.absolute_episode_number` so imports from MAL/AniList map seamlessly. | **Recommended** |
| **OD-3** | **Rating Scale Display vs. Storage** | Letterboxd uses `0.5–5.0` stars (10 increments), while IMDb, Trakt, and MAL use `1–10` integers. | Store all ratings in PostgreSQL as `SMALLINT` (`1` to `10`) for exact lossless compatibility with IMDb/Trakt/MAL and Letterboxd (`stars * 2`), and allow the user to toggle UI display between **5-Star (with half-stars)** and **10-Point (`8/10`)**. | **Recommended** |
| **OD-4** | **Profile Avatar Uploads vs. Preset/OAuth Avatars** | Supporting custom image uploads requires a Supabase Storage bucket (`avatars`) with RLS policies. | Support Google OAuth avatars + CourseVault's proven client-side `<canvas>` WebP compression (`max 256x256px`, `<50KB`) uploading to a public `avatars` Supabase Storage bucket[cite: 2]. | **Recommended** |
| **OD-5** | **Regional Streaming Availability ("Where to Watch") in Libya** | TMDB's watch-provider data (powered by JustWatch) has sparse coverage for Libya (`LY`). | Omit regional streaming provider badges in the initial MVP to avoid broken/empty UI blocks; revisit in Phase 7 with an optional user-selectable region fallback (e.g., `US`/`GB`/`MENA`). | **Recommended** |
| **OD-6** | **Supabase Free-Tier Inactivity Pause Prevention** | Free-tier Supabase projects pause after 7 days of inactivity. | Include a scheduled GitHub Actions workflow (`.github/workflows/supabase-keepalive.yml`) that runs a lightweight health-check ping every 5 days so the app stays online 24/7 at $0 cost during initial friend testing. | **Recommended** |
